# কুরআনুল কারীম (Quran Audio Bangla & Ayah Reader)

একটি আধুনিক, দৃষ্টিসুখকর ইসলামিক অডিও ও কুরআন পাঠের অ্যাপ্লিকেশন। এতে ১১৪টি সূরার বিশুদ্ধ বাংলা অডিও অফলাইনে শোনার ব্যবস্থা রয়েছে, সাথে রয়েছে লাইভ এপিআই-ভিত্তিক আয়াত-টু-আয়াত আরবি উসমানী তিলাওয়াত ও বাংলা অনুবাদ।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **সম্পূর্ণ অফলাইন অডিও (100% Offline Audio)**:
   - ১১৪টি সূরার সম্পূর্ণ বাংলা অডিও সরাসরি অ্যাপের মধ্যে যুক্ত (`001.mp3` থেকে `114.mp3`)।
   - ইন্টারনেট সংযোগ ছাড়াই যেকোনো সূরা সম্পূর্ণ অফলাইনে প্লে করা যায়।
   - ব্যাকগ্রাউন্ড প্লেব্যাক এবং লক-স্ক্রিন নোটিফিকেশন নিয়ন্ত্রণ (Android MediaSession API)।

2. **আয়াত-টু-আয়াত আরবি ও বাংলা অর্থ (Ayah-by-Ayah API & Offline Cache)**:
   - `AlQuran Cloud API` ইন্টিগ্রেশন।
   - ইন্টারনেট সংযোগ থাকলে প্রতিটি সূরার বিশুদ্ধ আরবি উসমানী হরফ ও বাংলা অর্থ স্বয়ংক্রিয়ভাবে লোড হয়।
   - **স্মার্ট অফলাইন ক্যাশিং (Offline Caching)**: একবার কোনো সূরার আয়াত লোড হলেই তা স্থায়ীভাবে ডিভাইসে সেভ হয়ে যায়, পরবর্তীতে ইন্টারনেট ছাড়াই তা পড়া যায়।
   - ইন্টারনেট না থাকলে স্পষ্ট অফলাইন নোটিশ প্রদর্শন করে, তবে অডিও প্লেব্যাক কোনো বাধা ছাড়াই চলতে থাকে।

3. **দৃষ্টিসুখকর ইসলামিক ডিজাইন (Islamic Aesthetics)**:
   - প্রিমিয়াম এমারেল্ড গ্রিন ও রয়েল গোল্ড থিম।
   - ঐতিহ্যবাহী আরবি ক্যালিগ্রাফি এবং ইসলামিক মেডেলিয়ন ডিসপ্লে।
   - বর্তমান বাজতে থাকা সূরার নাম, আরবি হরফ, অর্থ, অবতীর্ণের স্থান (মাক্কী/মাদানীয়) ও মোট আয়াত সংখ্যা প্রদর্শন।
   - বাস্তবসম্মত অডিও নিয়ন্ত্রক: প্লে/পজ, ১০ সেকেন্ড পেছানো/এগোনো, স্পিড পরিবর্তন (0.75x - 1.5x), লুপ/রিপিট মোড।

4. **দ্রুত সার্চ ও ফিল্টারিং**:
   - বাংলা নাম, ইংরেজি নাম, আরবি হরফ বা সূরা নম্বর (যেমন: `001`, `ফাতিহা`, `Fatihah`) দিয়ে দ্রুত খোঁজার ব্যবস্থা।
   - মাক্কী ও মাদানীয় সূরা আলাদা ফিল্টার করার সুবিধা।

## 📱 কীভাবে APK পাবেন (GitHub Actions Automatic APK Build)

এই রিপোজিটরিতে GitHub Actions স্বয়ংক্রিয়ভাবে চালু রয়েছে। 
1. রিপোজিটরির **Actions** ট্যাবে যান: [Actions Tab](https://github.com/metafixerhub/qural-bangla/actions)
2. সর্বশেষ `Build Quran Audio Bangla APK` ওয়ার্কফ্লোটি সিলেক্ট করুন।
3. নিচে **Artifacts** সেকশনে ক্লিক করে `Quran-Audio-Bangla-APK` ডাউনলোড করে অ্যান্ড্রয়েড ফোনে ইন্সটল করুন।
